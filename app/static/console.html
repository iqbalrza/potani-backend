Konsol Test Potani

Mulai

Konsol ini memanggil API backend yang sama dengan aplikasi mobile. Hanya aktif di mode dev.

Persiapan cepat

Memasangkan perangkat potani-demo-01 dan membuat satu pot bercahaya penuh bila belum ada.

Alur test yang disarankan

  1. Ukur: kirim bacaan tahap pre_plant lewat sesi.
  2. Rekomendasi: lihat kandidat, lalu pilih tanaman. Bila ada parameter di luar optimal, rencana dibuat.
  3. Rencana: tandai dikerjakan, majukan checkpoint, jalankan job scheduler.
  4. Ukur ulang tahap post_remediation, lalu jalankan run_verify_queue untuk melihat ACHIEVED atau REPLANNING.
  5. TaniBot dan Log agent untuk melihat tool yang dipanggil.
